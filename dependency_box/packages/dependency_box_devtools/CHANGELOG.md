## 1.0.0

- Initial release of the official Flutter DevTools extension for `dependency_box`.
- Interactive inspection of registrations, lifetime strategies, and instance heap allocation status.
- Scope hierarchy tree visualization and parent-child navigation.
- Dependency graph viewer with interactive zoom/pan controls.
- Health diagnostics and warnings for shadowed registrations and disposed scopes.
- Zero-overhead architecture with on-demand snapshot model and weak reference tracking.
