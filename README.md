# Dart Packages

A monorepo collection of standalone Dart packages.

## Packages

| Package | Description | Pub |
| :--- | :--- | :--- |
| [`dependency_box`](./dependency_box) | A high-performance, lightweight, and zero-dependency inversion-of-control (IoC) container and dependency injection box for Dart and Flutter. | [![pub package](https://img.shields.io/pub/v/dependency_box.svg)](https://pub.dev/packages/dependency_box) |
| [`dependency_box_devtools`](./dependency_box/packages/dependency_box_devtools) | Official Flutter DevTools extension for dependency_box to inspect registrations, scopes, dependency graphs, and health diagnostics. | [![pub package](https://img.shields.io/pub/v/dependency_box_devtools.svg)](https://pub.dev/packages/dependency_box_devtools) |
| [`caster`](./caster) | A safe, zero-dependency Dart casting utility with built-in fallbacks, custom defaults, and map extraction extensions. | [![pub package](https://img.shields.io/pub/v/caster.svg)](https://pub.dev/packages/caster) |
| [`enum_parser`](./enum_parser) | An ultra-fast, zero-dependency Dart utility for safely parsing and resolving enums from strings and dynamic values with multiple matching modes. | [![pub package](https://img.shields.io/pub/v/enum_parser.svg)](https://pub.dev/packages/enum_parser) |
| [`tristate`](./tristate) | An ultra-fast, zero-overhead Dart container for tri-state optional values, cleanly separating absent from explicitly null. | [![pub package](https://img.shields.io/pub/v/tristate.svg)](https://pub.dev/packages/tristate) |
| [`cloneable`](./cloneable/packages/cloneable) | ***(Beta)*** High-performance, strongly typed copyWith generator annotations and runtime contracts for Dart classes with explicit null support. | [![pub package](https://img.shields.io/pub/v/cloneable.svg)](https://pub.dev/packages/cloneable) |
| [`cloneable_generator`](./cloneable/packages/cloneable_generator) | ***(Beta)*** Code generator for cloneable, creating strongly typed copyWith implementations with explicit null support. | [![pub package](https://img.shields.io/pub/v/cloneable_generator.svg)](https://pub.dev/packages/cloneable_generator) |
