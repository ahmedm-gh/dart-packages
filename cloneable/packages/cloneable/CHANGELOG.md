# Changelog

## [1.0.0] - 2026-10-15

### Added

- Initial release of `cloneable` runtime package.
- `@Cloneable()` annotation with constructor configuration, inline support, and field filtering.
- `@CloneableField()` annotation with field-level ignore support.
- `cloneableUndefined` sentinel for distinguishing omitted arguments from explicit null.
- Zero external runtime dependencies.
